# diagnosing-bugs

先复现再定位困难问题。状态：手动试用，尚未晋升。

## 为什么保留或调整

保留能捕捉原症状的验证循环；真实项目的检查方式优先。

## 使用例子

> 这个流程偶尔丢数据，先找能复现的输入。

## 输入与依赖

先明确本次任务范围与需要的输入。依赖：以操作入口的当前工具检查为准。已有授权继续适用；缺少事实先检查，缺少用户决定再询问。

## 怎样算完成

原症状有失败信号；修复后原输入通过；临时探针已清理。

## 与相邻能力的关系

对照：diagnosing-bugs。按本次目的选择；名称相似不代表输出相同。
