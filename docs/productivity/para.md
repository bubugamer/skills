# para

按 PARA 重建用户选定目录。状态：已收录，列入默认发布清单。角色：任务入口。

## 为什么保留或调整

用户确认 PARA 专用定位，授权整改、更名，并在查看说明后明确审阅通过。保留盘点、查重、目录整体性判断与恢复记录；个人编号和目录映射放工作区配置，执行前核对整份计划的范围与冲突。


## 使用场景

| 具体场景 | 你可以怎样提出要求 | 用哪个 skill | AI 会怎样协助 | 最终产出 |
| --- | --- | --- | --- | --- |
| 资料目录混杂，想按 PARA 整理，但先看看方案。 | `$para` 检查这个目录，保留已有分类名，先给我看 PARA 整理方案。 | `$para` | 盘点文件，结合当前项目与长期责任分类，列出冲突和不确定归属。 | 可审阅的整理方案、保留项和待确认事项。 |
| 整理方案已确认，希望执行并能核对、恢复。 | `$para` 执行我们刚确认的方案，完成后核对文件完整性。 | `$para` | 检查路径与目标冲突，按授权移动，核对内容并记录操作。 | 整理后的目录、执行报告与逆向移动方案。 |

## 输入与依赖

选定目录、当前项目目标、持续责任和现有分类约定；执行需要审阅过的具体计划及相应授权。依赖：以操作入口的当前工具检查为准。已有授权继续适用；缺少事实先检查，缺少用户决定再询问。

## 怎样算完成

方案说明四类归属、保留与拆分决定及待复核项；获授权的执行保持文件内容，并记录实际结果与逆向移动方案。
