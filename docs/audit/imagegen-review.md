## 来源和两种入口

原有集合中的 imagegen 来自 [OpenAI 官方 skills](https://github.com/openai/skills/tree/main/skills/.curated/imagegen)，不是个人原创，也不属于 Matt 的技能。仓库仅记录外部能力，没有复制它的源码。

旧安装围绕 Image API 编写：通过 scripts/image_gen.py 生成、编辑或批量处理图片，真实 API 请求需要 OPENAI_API_KEY。当前系统同时提供同名 imagegen，默认使用内置图像工具，只有用户明确选择 API、脚本或相关模型工作流时才使用 CLI。不能因旧版需要密钥就说普通内置生图也需要用户配置密钥。

这一差别也得到 [官方图像功能说明](https://learn.chatgpt.com/docs/image-generation)支持：日常可在对话中生成或编辑图片，API 工作流另行配置密钥。当前实际可用工具和系统技能是本次现场判断的依据；官方文档中的模型名称与旧脚本默认值已有差异，后续 API 使用需现场核对，不在个人仓库固定一套模型默认值。

## 适合的使用场景

| 场景 | 用户可以怎样提出要求 | 合适入口 | 应有结果 |
| --- | --- | --- | --- |
| 文章、产品或活动需要一张配图 | 为这篇文章生成一张横版插画，采用克制的配色，不要文字 | 官方内置 imagegen | 可查看的配图，构图、尺寸与约束符合要求 |
| 需要透明背景素材 | 生成一张透明背景的咖啡杯素材 | 官方内置 imagegen | 具有实际透明通道的图片 |
| 修改已有图片 | 只替换背景，主体和构图保持 | 官方内置 imagegen，提供原图 | 检查过改动范围与保留内容的成品 |
| 明确要把多条图像任务接入程序 | 用 Image API 按这份任务列表生成，保存到指定目录 | 用户明确选择的官方 API CLI | 按指定参数和文件位置执行的 API 任务结果 |

“多张图片”本身不必转到 API；仍按用户指定方式和当前工具能力处理。截图属于记录已有屏幕，交互图表属于可视化，图像生成主要交付图片素材。
