## 来源与现有版本

来源为 [Vercel Labs 的 agent-browser](https://github.com/vercel-labs/agent-browser)，不属于用户要求直接跳过的 OpenAI 官方集合。它是浏览器自动化 CLI，可以读取页面、操作表单、获取截图和提取数据。[作者文档](https://agent-browser.dev/)介绍了快照与元素引用的操作方式。

本机旧技能入口 SHA-256 为 9caba4d013daf731c9f78803c9a73178400c04e2c033541939d77d0f5bc9248c，与原 catalog 记录一致。当前 CLI 为 0.39.1，自带可通过 skills get core 读取的配套说明，明确采用每个任务自己的会话。旧技能说明与当前 CLI 配套资料不同，不应把最初保存的命令清单当作所有版本永久适用的说明。

本仓库只有外部能力登记和使用页，没有复制第三方源码。本轮不更新或迁移本机安装，也不统计历史使用次数。

## 具体场景

| 场景 | 用户可以怎样提出要求 | 工具如何协助 | 预期结果 |
| --- | --- | --- | --- |
| 检查网页交互 | 检查这个测试页的表单，填写样例并确认结果 | 读取当前页面，识别元素，按范围填写和点击，再核对页面状态 | 可复核的操作结果与问题 |
| 从动态页面提取数据 | 把这个页面已经显示的商品列表整理成表格 | 操作页面并提取真实显示的数据 | 带来源的结构化列表 |
| 为阅读获取特殊网页内容 | 这个页面需要展开，帮我取得正文 | 作为 site-unlocker 可选浏览器后备，执行必要交互 | 经正文判定的材料 |
| 记录网页状态 | 保存这个指定页面的截图 | 使用选定会话截图并核对文件 | 对应页面的图片与位置 |

agent-browser 提供浏览器操作；site-unlocker 维护获取正文、判断完整性和处理访问障碍的方法。两者有调用关系和重叠场景，但交付目标不同。当前内置浏览器或官方 Playwright 能完成任务时，同样可以沿用；无需为一次任务同时开多套重复会话。

## 五列取舍建议

| 内容 | 取舍 | 原因 | 建议维护方式 | 对使用的影响 |
| --- | --- | --- | --- | --- |
| 浏览器操作能力 | 建议保留为外部工具 | 可服务交互检查、数据提取和特殊正文获取 | 继续由 Vercel Labs 维护 | 保留 CLI 工作流的选择 |
| 第三方 SKILL.md 与命令大全 | 不复制或重写为个人版本 | 当前 CLI 已有配套说明，旧快照存在漂移可能 | 使用当前 CLI 的配套资料，仓库仅记用途和限制 | 减少维护第二套手册 |
| 快照与交互流程 | 沿用工具方法，实际核对结果 | 页面变化后需要重新观察，不能只按命令成功判断业务结果 | 当前配套说明负责具体命令 | 明确真正完成的操作 |
| 会话和登录状态 | 每次任务选定自己的会话，按需使用已有授权状态 | 避免误用默认共享会话或其他任务的页面 | 保留在用户运行环境，不进入公开源码 | 操作范围和结果对应当前任务 |
| 与 site-unlocker 的关系 | 保留工具与方法的分工 | 前者执行页面操作，后者判断正文获取结果 | 原有后备关系保持，不新增个人工具副本 | 既可辅助阅读，也可独立处理网页任务 |
| 是否作为首选 | 根据当前工具与实际可用性选择 | 已有内置工具与其他浏览器方案，命令存在不等于所有场景都可用 | 本轮实际检查与后续真实任务分别记录 | 不把单个本地测试外推为所有站点验证 |

## 实际检查范围

已读取旧入口、会话和元素引用参考、表单模板，核对本机 CLI 版本、帮助和配套 core 说明。上游来源与能力说明来自作者资料，具体可用性按本轮本地检查结果记录。

本地检查使用临时目录中的合成表单、仅绑定 127.0.0.1 的 HTTP 服务和专用短会话名；配置独立，不接入用户已有登录状态、浏览器会话或任何外部网站。每次测试结束只关闭本次创建的会话。具体结果在下文记录，不以帮助返回成功代替页面交互验证。


### 实际结果

| 输入或操作 | 实际观察 | 覆盖范围 |
| --- | --- | --- |
| 独立新会话打开本地合成表单 | 正确返回页面标题和 URL | 浏览器启动与本地导航 |
| 读取页面及交互快照 | 返回 Email 文本框和 Submit local form 按钮的元素引用 | 基础页面观察 |
| 使用观察到的引用填写 review@example.test 并读回 | 与输入一致 | 基础填写与读取 |
| 点击本地提交按钮，重新读取快照和结果 | 显示 Confirmed: review@example.test | 表单事件与结果核对；没有向外部服务提交 |
| 关闭本次会话 | 正常退出 | 未关闭其他会话 |

先前测试中，过长的会话／命名空间组合触发 socket 路径长度限制，改用短的独立名称后解决。测试脚本也修正了对元素引用标签的过窄解析。这些是本轮测试设置与脚本修正，没有修改 agent-browser。

另有一项未解决的观察：显式指定临时 profile 时，虽然导航返回正确页面标题，但快照没有交互元素或等待字段超时。原因未定位；采用不复用 profile 的独立新会话后，上表流程通过。因此此次只确认后一种基础路径可用，不声称持久化 profile、用户登录复用、真实网站、截图、录屏或所有平台都已验证。

原审阅建议为沿用外部工具及当前 CLI 配套说明；用户确认与最终收录方式见下节。
