# 工作区配置示例

将需要的部分复制到自己的项目 docs/agents/skill-workspace.md，并从项目 AGENTS.md 引用。不要在公共集合中填写个人路径或生产配置。

- 知识库根目录：用户指定的本地目录。
- Wiki 根目录、首页、主题页和 MkDocs 配置：从现有工作区读取。
- 阅读保存策略：普通讨论留在会话；明确保存或持续授权时才写。
- 下载目录：默认当前用户的 Downloads/sourcesget，可由本次请求覆盖。
- 外部浏览器能力：优先当前 Codex 工具；必要时选择已安装的 CLI。
- 登录状态：保存在本地并排除 Git，只记录路径，不记录值。
- 项目发布与线上验收负责人：按项目现有规则填写。
