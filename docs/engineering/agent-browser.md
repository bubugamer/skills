# agent-browser

浏览器交互与抓取。状态：外部依赖，继续从上游维护来源获取。

## 为什么保留或调整

用户已确认作为 Vercel Labs 外部浏览器工具保留，归 engineering；个人库只登记用途、选择依据和限制，不复制或重写第三方实现。当前 CLI 自带与版本匹配的使用说明，与 site-unlocker 的正文获取方法分工见 [本轮审阅](../audit/agent-browser-review.md)。独立临时会话下的本地基础表单交互已通过；显式临时 profile 曾出现空快照或等待超时，原因未定位。真实网站、登录复用和截图未验证。本机安装未改，留待统一处理。


## 使用场景

| 具体场景 | 你可以怎样提出要求 | 用哪个 skill | AI 会怎样协助 | 最终产出 |
| --- | --- | --- | --- | --- |
| 检查指定测试页面的表单交互 | `$agent-browser` 检查这个测试页的表单，填入样例并确认结果。 | `$agent-browser` | 使用本次任务自己的会话，读取页面后执行已授权操作，再核对页面实际显示的结果。 | 可复核的交互结果和发现的问题。 |
| 从动态页面提取已显示的数据 | `$agent-browser` 把这个页面显示的商品列表整理成表格，附来源。 | `$agent-browser` | 观察页面，按范围展开或翻页，提取实际可见的数据，说明访问或完整性限制。 | 带来源的结构化列表及覆盖范围。 |

## 输入与依赖

用户指定的 URL、操作目标和执行范围；需可用的 agent-browser CLI 与浏览器。优先读取当前 CLI 配套说明，使用本次任务自己的会话；涉及登录时沿用已授权方式。依赖：以操作入口的当前工具检查为准。已有授权继续适用；缺少事实先检查，缺少用户决定再询问。

## 怎样算完成

按指定网页和已授权范围完成操作，核对实际页面状态或提取结果；仅关闭本次会话，返回结果及实际文件位置。

## 与相邻能力的关系

对照：当前内置浏览器或官方 Playwright 工具（通用浏览器操作）；site-unlocker（特殊正文获取的方法与结果判定）。按本次目的选择；名称相似不代表输出相同。
