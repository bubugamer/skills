## 输入与依赖

页面任务、用户、平台、已有界面与设计系统、请求阶段；资料检索需要独立可用的上游运行目录（scripts/core.py 与 data/），通过 --runtime 或 UI_UX_PRO_MAX_RUNTIME 指定。Python 3 为本地适配工具依赖；无外部运行目录时不编造搜索结果或自动安装。依赖：以操作入口的当前工具检查为准。已有授权继续适用；缺少事实先检查，缺少用户决定再询问。

## 怎样算完成

围绕真实页面任务给出有依据的布局、视觉与交互建议，尊重现有设计系统和用户要求；实现或保存仅在请求范围内，并核对实际页面或文件结果。检索返回与设计建议不代替页面体验验收。
