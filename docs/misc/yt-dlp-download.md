# yt-dlp-download

下载或检查用户指定媒体。状态：正式集合。

## 为什么保留或调整

保留单条默认、集合范围选择和防覆盖；输出位置改为当前用户 Downloads。

## 使用例子

> 下载这条视频，只要音频。

## 输入与依赖

先明确本次任务范围与需要的输入。依赖：以操作入口的当前工具检查为准。已有授权继续适用；缺少事实先检查，缺少用户决定再询问。

## 怎样算完成

保存文件存在且符合媒体类型；合集未被意外全部下载。

## 与相邻能力的关系

对照：无直接同类；属于专用工具。按本次目的选择；名称相似不代表输出相同。
