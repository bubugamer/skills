# Authentication And State

## 登录原则

- 不让用户把密码直接发到聊天里。
- 优先让用户在浏览器窗口里自己登录。
- 登录成功后，保存本地认证状态，后续复用。

## 推荐做法

### agent-browser

- 用 headed 模式打开站点
- 导航到登录页
- 完成登录后保存 state
- 下次先加载 state，再直接打开目标页面

### playwright

- 用 `--headed` 打开站点
- 手动完成登录
- 在同一个会话里继续抓内容

## 本地状态文件

认证状态文件应该：

- 放在本地工作目录或用户私有目录
- 不进入 git
- 不发回聊天

## 什么时候必须停下

如果遇到这些情况，不要继续假装能抓到内容：

- 登录后仍然跳回登录页
- 2FA 未完成
- 授权弹窗无法通过
- 页面虽然打开了，但正文仍然不可见

这时应该明确告诉用户还缺什么。
