# Deep Research

Define the question, intended use, scope, and relevant dates from the user's context. State material assumptions; ask only when missing information would change the investigation.

Search with the tools available in the current environment. Prefer original documents, data, research, and official technical sources. Follow evidence gaps and counterarguments; revise the investigation when new evidence changes its direction. Read [research-method.md](references/research-method.md) for complex or disputed questions.

Check key claims against the actual source passages, including numbers, dates, scope, conditions, and contrary evidence. Distinguish independent evidence from repeated reporting. Separate source facts, your synthesis, recommendations, and unresolved questions. Source counts, URL availability, and text similarity do not establish that a claim is true.

Deliver the answer in the conversation, with sources next to the claims they support. Explain the conclusion, significant alternatives, and what remains uncertain. Match depth to the question, evidence, and requested limits.

For an agreed long-running investigation or a requested research bundle, read [evidence-records.md](references/evidence-records.md) to retain sources, exact excerpts, and review notes. Select the record location within that agreed scope.

When the user requests a standalone report, read [reports.md](references/reports.md). Confirm its destination and formats from existing instructions or the request, then create and check those outputs.

Finish when the question has a supported answer or a clearly explained evidence gap, and the requested deliverables have been checked. State the actual verification scope.
