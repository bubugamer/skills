# Brief Format

Use this output shape unless the user explicitly asks for another format.

## 1. 结论

Start with a short plain-language takeaway for the whole batch:

- what stood out
- whether anything deserves immediate click-through

Keep this to one short paragraph.

## 2. 本期值得点开

Include only the strongest items.

For each item:

- title
- one or two sentences on why it matters
- direct source link

Aim for a small set. If everything is mediocre, say so instead of padding this section.

## 3. 可先放入稍后阅读

Use this for items that look useful but are not urgent.

For each item:

- title
- why it is useful but not top priority
- direct source link

Filter weak items quietly by default. Only explain what was filtered out if the user explicitly asks, or if a source was unreadable and that gap materially changes the brief.

## 4. 下一步

Offer only the next actions that make sense now:

- 深入读其中一条
- 继续扩大来源
- 下次继续跟踪同一批来源
- 暂不处理

Keep the brief readable in one screenful when possible.
