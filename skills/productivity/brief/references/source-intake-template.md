# Source Intake Template

Use this template when the user wants to define or refine a recurring source set for `brief`.

## 主题

- What topic or domain should this briefing cover?

## 信息源

- Source name:
- Source type: site / newsletter / account / feed / channel / other
- URL or handle:
- Why it belongs in the set:

Repeat for each source.

## 关注什么

- Which themes, keywords, people, or developments should be prioritized?

## 降权什么

- Which patterns should be deprioritized?
- Examples: reposts, hot takes, thin summaries, fundraising noise, generic product announcements

## 输出偏好

- More “front page” or more “research watchlist”?
- Very short or moderately detailed?
- Prefer more links or more explanation?

## 节奏

- Is this a one-off brief or a source set for repeated use later?
