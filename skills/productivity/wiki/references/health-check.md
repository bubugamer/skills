# 健康检查

用户要求检查知识库或修复指定问题时读本篇。先确认范围、页面角色与导航模型；只读检查交付报告，有修复授权时再处理相应问题。

## 检查内容

### 断链与导航错误

- 检查普通 Markdown 链接中的页面、附件和章节目标；按项目支持情况检查双中括号、别名与章节。名称重复导致歧义时报告候选，不能用任意同名文件判定通过。
- 区分相对于源页面的路径、站点路径、外部网址和项目特有语法。外链是否在线需单独核对，未访问不能报告正常。
- 按 [导航分工](navigation.md) 比较首页、主题页与站点页面树；发现不存在目标、应列未列、重复条目或失效入链。
- 改名或移动后，复查新位置的出链和全库入链；纯首页、日志和附件不按内容页规则硬补来源。

### 待复核内容

- 找出待核验标记、新旧结论冲突和新增未审段落，说明涉及主张及各自证据。
- 将旧页面与旧草稿作为复核线索；沿用项目的复核周期。没有周期约定时可报告页面日期分布，不把六个月或三十天当作错误判据。
- 版本、价格和产品行为等易变事实按来源核实；长期稳定概念不因日期较旧直接判错。

### 可发现性与关联

- 找出从首页、主题页或其他有效入口不可达的页面。
- 单列只有目录链接、缺少知识关联的页面，并建议具体关联对象及关系；它们不等于断链。

### 内容与属性缺口

- 使用支持项目格式的 YAML 解析方式读取属性，包括多行 `sources`，再按内容页、导航页与维护页分别判断。
- 复核关键断言的来源是否实际支持结论；空来源列表、失效出处与只有标签没有链接是线索，需结合正文判断。
- 区分个人决策、综合推断与需要外部证据的事实；不为通用常识机械堆引用。
- 草稿久未更新可建议继续整理或归档；状态推进仍需用户对相应内容的明确确认。

## 工具与覆盖范围

先核对现有工具的参数、写入行为和实际支持的格式。脚本结果是线索；目录完整、链接可解析都不证明内容正确。没有工具覆盖的检查，结合实际页面处理并标明未检查范围。

### 配套只读工具

使用 skill 自身 `scripts/lint_wiki.py`，运行环境为 Python 3.10+ 和 PyYAML。脚本路径从本 SKILL.md 所在目录解析；`--root` 是页面目录。相对页面参数和相对 `--nav` 路径均以该目录为基准。

```bash
# 纯 Markdown 知识库；替换示例路径。
python3 <skill-dir>/scripts/lint_wiki.py --root <pages-root> --json

# 已确认采用精简首页、主题页和完整 MkDocs 导航的项目。
python3 <skill-dir>/scripts/lint_wiki.py --root <pages-root> \
  --nav ../mkdocs.yml --home-scope topics --wikilinks --json
```

按项目实际情况选择参数，不把命令示例当作现成配置：

- `--home`、`--log` 默认分别为 index.md、log.md；项目使用其他名称时显式传入。
- `--topic` 指定额外主题入口，`--maintenance` 指定其他维护页，`--exclude` 指定不纳入本次扫描的路径；均可重复。
- `--home-scope` 默认 none，只检查已有链接；确认首页应覆盖所有主题或内容页时，选 topics 或 all。
- 只有项目支持双中括号语法时传 `--wikilinks`；否则这些链接列为未检查。
- `--review-after-days`、`--draft-after-days` 仅在项目有复核周期时传入；`--today` 可明确日期。超过周期只列为复核线索。
- 工具始终只读，没有 `--dry-run` 或写入模式。返回码 0 表示未发现断链、导航错误或执行错误，1 表示存在断链或导航错误，2 表示读取／配置错误；内容与复核建议仍需查看报告。空目录的 `--json` 也返回 JSON。

工具覆盖普通行内和引用式 Markdown 链接、常见章节锚点、附件、可选双中括号，以及显式 MkDocs nav。配置中的其他自定义 YAML 标签不会执行或重写。多行来源正常解析，首页、日志和导航型主题页分别处理。

外链在线状态、站点根路径、特殊渲染器语法、嵌入组件和自定义锚点规则不保证覆盖，必要时另查实际渲染；代码块和注释中的示例链接不作为正文断链。来源列表或链接存在不证明其支持结论，证据强度仍需阅读判断。

旧版覆盖首页的索引生成器不随新版发布。按 [导航说明](navigation.md) 编辑具体页面与导航，使用只读工具检查结果；不使用旧算法生成全页首页。

## 报告与修复

报告包含扫描范围、已检查的项目及未覆盖部分。问题列表按影响排序，可分为：断链／导航错误、待复核、关联不足、内容缺口。

每项写出页面或章节、实际证据、对使用的影响和建议处理；将可确认错误与需要判断的事项区分开。缺少数据时不捏造数量或冲突持续时间。

按本次授权修复后，复查受影响链接、导航、来源和内容；变更日志记录本次实际修改与仍待处理事项。只完成部分检查时，明确结果适用的范围，不称整库健康检查全部通过。
