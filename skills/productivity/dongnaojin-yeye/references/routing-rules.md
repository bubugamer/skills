# Routing Rules

这个文件定义“动脑筋爷爷”的固定落库链条。仅在用户已要求保存时应用这些规则。工作区来自用户或项目配置：

`<knowledge-root>`

## 0. 落库前置门槛

在进入任何链路之前，先判断是否已经真正获取到内容。

### 允许落库

- 已获取正文
- 已获取完整转写
- 已获取足够长、能支持判断的有效摘录

### 不允许落库

- 只有链接，没有正文
- 只有标题、作者、发布时间
- 只有短链接跳转关系
- 登录墙、平台不支持页、错误页、空白壳页面
- 无法判断内容主题和质量

### 规则

- 未获取内容时，默认**不写阅读队列**、**不写伴随笔记**、**不写主题沉淀**。
- 先在回复里说明“当前拿不到正文，所以不落库”。
- 只有用户明确要求“先记入口”时，才允许单独保存不可读链接。

## 1. 内容收藏

### 目标位置

- 阅读队列：
  `<knowledge-root>/03-Resources/articles/阅读队列.md`
- 原始材料目录：
  `<knowledge-root>/03-Resources/articles/`

### 规则

- 用户要求收藏的新内容先进入阅读队列，但前提是已经获取到可读内容。
- 如果用户当前只是问“值不值得读 / 要不要现在看 / 要不要学”，这属于第一阶段，在用户要求保存时，**只写阅读队列**，不要顺手创建伴随笔记。
- 如果原始内容是本地文件，保留原文件路径并写入阅读队列。
- 如果原始内容是网页或链接，只有在成功拿到正文后才记录标题、来源、链接、日期和处理诉求。
- 如果网页或链接当前不可读，默认不写阅读队列。
- 阅读队列按**当前状态**分为不同子队列，默认至少包含：
  - `现在读`
  - `先收藏`
  - `可跳过`
  - `已完成`
- 当只是做第一阶段判断时：
  - `现在读` / `先收藏` / `可跳过` 直接写入对应子队列。
  - 不创建伴随笔记。
- 当某条内容已经完成共读、摘要或深入处理后，再移动到 `已完成` 子队列。

## 2. 共读 / 摘要 / 翻译 / 背景补充 / 出处追溯

### 目标位置

- 伴随笔记目录：
  `<knowledge-root>/03-Resources/articles/共读笔记/`

### 规则

- 这条链路属于第二阶段，不要在第一阶段的“值不值得读”判断里自动进入。
- 每篇已获取正文的内容一份伴随笔记。
- 优先新建独立笔记，不直接改主题知识文档。
- 伴随笔记文件名建议：
  `YYYY-MM-DD-<主题短名>.md`
- 如果同一内容已有伴随笔记，优先追加新章节，不覆盖旧结论。
- 如果还拿不到正文，不要创建伴随笔记。
- 共读笔记按**结论单元**写，不按**每轮问答**写。
- 当用户还在对同一个点反复追问、纠错、确认理解时，先继续回答，暂不落库。
- 只有当这个点已经收束，或用户明确说“OK / 可以了 / 总结一下 / 开始下一题”时，才把稳定结论写入伴随笔记。
- 写入时只保留结论性内容，不记录来回追问、误解过程、中间版本解释或纠错轨迹。
- 如果本轮还没有收束，就在回复中明确说明“本轮暂未写入共读笔记，等待当前问题收束后再保存结论”。

## 3. 内容衍生的学习计划

### 目标位置

- 计划：
  `<knowledge-root>/01-Projects/【学习】<主题>/计划.md`
- 过程记录：
  `<knowledge-root>/01-Projects/【学习】<主题>/进度记录.md`

### 规则

- 只有当用户明确要求“基于这些内容给我做学习计划”时才创建。
- 计划和记录都归入 `01-Projects`，不要写进 `02-Areas`。

## 4. 内容衍生的调研计划

### 目标位置

- 调研计划：
  `<knowledge-root>/01-Projects/【调研】<主题>/调研计划.md`
- 调研记录：
  `<knowledge-root>/01-Projects/【调研】<主题>/调研记录.md`

### 规则

- 只有用户明确要求创建独立调研计划时才使用这条链路。
- 调研计划写“要回答的问题”和“下一步怎么查”，不要把它写成最终结论。

## 5. 内容引发但未裁决的想法

### 目标位置

- Inbox：
  `<knowledge-root>/03-Resources/_Inbox/_Inbox.md`

### 规则

- 只有仍未裁决的想法才进入 Inbox。
- Inbox 不写状态，不写进度，只记录想法本身。

## 6. 稳定知识沉淀

### 目标位置

- 对应主题目录：
  `<knowledge-root>/02-Areas/`

### 规则

- 原始材料、转写、伴随笔记默认留在 `03-Resources`。
- 只有当结论已经稳定、未来会复用、值得长期保留时，才提炼进 `02-Areas`。
- 进入 `02-Areas` 的内容应该是“提炼后的结论”，不是原始阅读过程。
- 不直接改写历史主题正文，除非用户明确同意。

## 7. 目录和文档操作边界

- 允许新建目录。
- 允许调整目录结构。
- 允许新建记录文档。
- 不允许未经确认直接改历史正文。
- 在已授权的保存范围内采用“先追加、后提炼”，而不是“先重写、后整理”。
