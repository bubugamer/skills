# 选择一个合适的 skill

读取 references/routes.md，按任务目的选择，优先保留用户明确指定的能力。
给出一个首选、最多两个有实质差异的备选，说明理由、必要依赖与一句可直接使用的指令。
区分正式能力、手动试用和第三方能力。只推荐，不安装、不替用户启动目标任务，也不把试用项当作正式能力。
目标需要多个步骤时，说明先后关系；只列本次确实需要的步骤。
完成条件：用户知道现在该选什么、为什么，以及是否还缺工具或工作区信息。
