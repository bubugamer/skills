# 能力路由

| 任务目的 | 首选 | 条件与边界 |
| --- | --- | --- |
| 发现待办与想法，提醒并跟进 | remind | 当前集合，结合使用页检查已知限制；待办与想法区分清楚；提醒基于已知事实；按用户确认跟进状态，不强制目录或周／日计划。 |
| 阅读、翻译、共读问答与阅读事务 | read | 当前集合，结合使用页检查已知限制；回答由实际材料支持；阅读范围与保存范围清楚；连续追问沿用上下文；保存笔记时报告实际位置。 |
| 围绕目标持续学习课程、领域或技能 | teach | 当前集合，结合使用页检查已知限制；手动选择；课程紧扣学习目标且挑战程度合适；可信来源可追溯；练习及时反馈；课程、参考材料与学习记录便于后续学习和复习。具体产物服从本次明确要求。 |
| 按 PARA 重建用户选定目录 | para | 当前集合，结合使用页检查已知限制；方案说明四类归属、保留与拆分决定及待复核项；获授权的执行保持文件内容，并记录实际结果与逆向移动方案。 |
| 获取特殊网页的真实正文 | site-unlocker | 当前集合，结合使用页检查已知限制；成功产物有正文和来源；登录墙不能当作成功。 |
| 应用和维护多种文风，写作、润色与审稿 | writing-styles | 当前集合，结合使用页检查已知限制；输出符合所选文风与请求形式；保留事实、来源、立场和确定程度；完成基础语言检查；文件修改仅限已授权范围 |
| 重新解释上一段回答 | wait-what | 当前集合，结合使用页检查已知限制；手动选择；补足必要上下文，以简明中文重讲，并沿用相关项目术语。 |
| 获取多来源金融市场数据 | akshare-api | 当前集合，结合使用页检查已知限制；代码、来源、日期、复权口径齐全；缺失结果显式说明。 |
| 读取沪深行情与历史数据 | tdx-api | 当前集合，结合使用页检查已知限制；返回代码完整；日线确认日期；不拿历史值冒充实时值。 |
| 下载或检查用户指定媒体 | yt-dlp-download | 当前集合，结合使用页检查已知限制；实际文件存在，媒体类型、音频格式与所选范围符合要求；换格式保留已有文件，记录跳过须核实文件；报告成功、已有文件及失败的实际路径与结果。 |
| 维护 DeepCoffee 开发、运维与知识流程 | deepcoffee-dev | 当前集合，结合使用页检查已知限制；手动选择；按请求完成对应流程；报告实际提交、检查、部署、维护或知识库结果，按原约定交接线上验收；缺失脚本与未完成动作明确说明。 |
| 维护 Markdown 长期知识、关联与导航 | wiki | 当前集合，结合使用页检查已知限制；手动选择；完成本次授权范围的知识更新或只读查询；核对来源、链接、主题入口和所用站点导航，说明待核验事项及未检查范围。本地站点操作以实际服务状态验收。 |
| 读取社交时间线的结构化条目 | social-feed | 当前集合，结合使用页检查已知限制；手动选择；能选择当前工具；缺失或过期登录状态明确失败；时间与跳转链接由真实卡片获取。 |
| 浏览器交互与抓取 | agent-browser | 外部能力，先确认已安装；按指定网页和已授权范围完成操作，核对实际页面状态或提取结果；仅关闭本次会话，返回结果及实际文件位置。 |
| 从外部技能生态寻找新能力 | find-skills | 外部能力，先确认已安装；返回与需求相关的候选、原始来源、内容及已有能力比较，明确适配条件和仍待确认事项；未搜索到时如实说明。本轮发现结果不自动纳入集合或安装。 |
| 多来源证据研究 | deep-research | 当前集合，结合使用页检查已知限制；围绕明确研究问题给出可追溯的结论、主要证据、反例与不确定性；关键断言回到原文核对。独立报告及格式按用户明确要求交付，脚本结果仅作辅助，不以数量或评分代替事实核验。 |
| 设计资料库与风格建议 | ui-ux-pro-max | 当前集合，结合使用页检查已知限制；围绕真实页面任务给出有依据的布局、视觉与交互建议，尊重现有设计系统和用户要求；实现或保存仅在请求范围内，并核对实际页面或文件结果。检索返回与设计建议不代替页面体验验收。 |
| 创建、改进与评测技能 | skill-creator | 当前集合，结合使用页检查已知限制；按用户要求交付新建或改进后的技能及配套资料；实际评测时给出结果、证据和限制，错误单列，不把文件检查说成行为改进。 |
| 通过访谈捕捉写作素材与片段 | writing-fragments | 当前集合，结合使用页检查已知限制；手动选择；捕捉可用原话、观点、细节和未完成想法，追加到选定素材文件；保存前读取现状并保留用户修改，不提前安排文章结构。 |
| 将已有素材逐块组织成文章 | writing-shape | 当前集合，结合使用页检查已知限制；手动选择；读取完整素材，明确读者基础与开头主张，逐块形成连贯文章；原素材保持，写入前读取现状，缺失材料明确指出，由用户决定结束。 |
| 逐次选择叙述方向，共同推进文章 | writing-beats | 当前集合，结合使用页检查已知限制；手动选择；明确读者基础，每次提供可达的叙述方向，只写入用户选定的一步并更新已铺垫概念；保留修改，文章在叙述完成时结束。 |
| 编写清楚、按需加载的 AI 指令文档 | writing-for-agents | 当前集合，结合使用页检查已知限制；指令的引用条件明确、层级与完成条件清楚，同一规则只维护一处；按请求范围交付文档调整，技能调用配置使用当前 Codex 约定。 |
