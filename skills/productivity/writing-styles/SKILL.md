# Writing Styles

Apply a chosen voice to the user's material and requested deliverable. Keep shared writing and review rules here; load only the relevant style reference.

## Choose a style

- Use [bbs](references/styles/bbs.md) for Chinese forum posts, experience sharing, and a conversational voice for peers.
- Use [research-analysis](references/styles/research-analysis.md) for analytical prose based on available material, especially concise conclusions supported by evidence.
- When the user names a profile, read `references/styles/<profile>.md`. If it is missing, explain and ask for a sample or the desired characteristics when needed.
- Without a named style, follow the supplied voice, audience, and venue. Chinese text alone does not select bbs. Ask only when a style choice would materially change the result.

## Preserve substance

Keep the user's facts, opinions, experiences, source references, dates, and degree of conviction. Use supplied details rather than inventing stories or stronger certainty. Flag contradictions between a claim and the available evidence instead of silently changing the author's position.

Match the intended audience's vocabulary. Preserve intentional colloquial language, rhythm, and useful technical terms. Choose structure to fit the text and request; a style profile supplies guidance rather than a compulsory template.

## Deliver the requested form

- For a draft, continuation, or condensation, return usable prose in the chosen style. When asked only to record, discuss, or outline, keep the response at that stage.
- For review or proofreading of supplied text, give focused suggestions in the conversation: locate the wording, explain the issue, and suggest a replacement. Distinguish language errors from optional style choices. Preserve the source file and leave a complete rewrite for an explicit rewrite request.
- When explicitly asked to rewrite or polish supplied text, return a revised version in the conversation; the original file stays intact unless file editing is also requested.
- When explicitly asked to edit a specified file, make the requested changes there, preserving substantive facts, sources, and positions. Existing authorization for that scope remains valid.

## Check the language

Check grammar, typos, missing or duplicated characters, punctuation, word choice, collocations, and idioms in every style. Correct real errors while retaining deliberate informal wording. Then use the selected profile's self-check and keep commentary proportional to the request.

## Maintain the collection

When asked to add a style, create `references/styles/<style-name>.md` from the user's examples or stated preferences. Record distinctive voice, useful phrasing, editing choices, and checks; include only sections that help apply that style. Add its selection condition above and a representative scenario in `evals/evals.json`. Keep common rules here and validate the updated skill.
