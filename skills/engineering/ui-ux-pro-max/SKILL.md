# UI/UX Pro Max

Understand the page's primary task, users, platform, existing design system, and requested stage: advice, implementation, or saving confirmed rules. Resolve these from the current project and conversation.

Read [personal-design.md](references/personal-design.md) for the user's established preferences. Apply the relevant principles within the current request and project constraints.

Use focused reference searches when they help the decision. Read [reference-search.md](references/reference-search.md) for the external runtime, available domains and stacks, and data-quality limits. Choose the actual platform; a small adjustment can use one relevant search without generating a full design system.

Explain the proposed information hierarchy, visual choices, interactions, and tradeoffs. Treat search results as options to assess against the real task. Keep labels and product flows understandable to the intended user.

Implement when requested, using the project's components and conventions. Inspect the actual page and relevant interactions, states, and viewport behavior; distinguish a proposal from an implemented and checked result.

When saving or updating confirmed design rules, read [design-records.md](references/design-records.md). Compare with existing files, retain prior decisions, and write within the agreed scope.
