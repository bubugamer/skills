# Skill Creator

Establish the user's task, intended outcome, realistic usage, and requested change. Read existing skills and feedback before deciding what to create, revise, or evaluate. Keep creation, maintenance, and evaluation in this one entry; choose the work needed for the current request.

For creation and revision, read [creation.md](references/creation.md). Write a focused entry with clear triggering and completion criteria; place detailed methods and reusable resources where they are needed. Preserve the existing purpose, naming, and invocation policy unless the requested change requires otherwise.

When evaluation is useful, identify the versions, tasks, and observable success criteria. Keep real task performance separate from description triggering. For task comparisons and human review, read [task-comparison.md](references/task-comparison.md). For trigger probes and description revision, read [trigger-evaluation.md](references/trigger-evaluation.md).

Agree on the cases, comparison, execution scope, and resource limits from the current request and existing authorization. Use isolated workspaces for outputs. Loading this skill does not itself authorize additional agents, model calls, installations, or changes to the target skill.

Run only the chosen checks. Preserve actual outputs, failures, and evidence for each judgment. Distinguish execution errors and timeouts from a valid negative result; incomplete runs cannot pass. Use independent comparisons where available and authorized, otherwise explain the limits of sequential self-checks.

Read [result-records.md](references/result-records.md) for formats and the local summary and review tools. Missing timing or token data remains unknown. A trigger marker, file validation, and real task success are different results.

Explain changes, findings, counterexamples, uncertainty, and the smallest useful improvement. Revise the target only within the user's requested scope, then repeat the checks that the change affects. Deliver the skill and supporting files, plus actual evidence and report locations when evaluated, without claiming unrun evaluations.
